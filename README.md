## 🚀 Démarrage rapide

### Prérequis
- Node.js 20.19 ou supérieur
- npm ou yarn / pnpm

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/<votre-identifiant>/mariage2.git

# Accéder au dossier
cd mariage2

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

L'application sera accessible sur [http://localhost:3000](http://localhost:3000).

### Scripts disponibles

- `npm run dev` : Lance le serveur local de développement.
- `npm run build` : Génère les fichiers optimisés pour la production dans le dossier `dist/`.
- `npm run preview` : Prévisualise le build de production localement.
- `npm run lint` : Vérifie les types avec le compilateur TypeScript.
